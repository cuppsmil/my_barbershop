
# My Barbershop

Учебный проект на C# для управления барбершопом: Веб-приложение для комфортного управления таблицами из базы данных сети брабрешопов, также помогает записываться на стрижку клиентам

## О проекте

**My Barbershop** - приложение, которое помогает в администрировании базами данных (CRUD функционал), записи клиентов на стрижку
Проект разработан в Visual Studio 2022 на платформе .NET.

## Возможности

<!-- TODO: оставьте только то, что реально реализовано -->
- Просмотр списка услуг и их стоимости
- Запись клиента на стрижку к выбранному мастеру
- Управление мастерами и расписанием
- Учёт клиентов и истории посещений

## Технологии

- C#
- .NET 8
- ASP.NET Core
- PostgreSQL

## Установка и запуск

### Требования
- [Visual Studio 2022](https://visualstudio.microsoft.com/) с установленной рабочей нагрузкой для разработки на .NET


### Шаги

1. Клонируйте репозиторий:
```bash
   git clone https://github.com/cuppsmil/my_barbershop.git
```
2. Откройте файл `My_Barbershop.sln` в Visual Studio.
3. Дождитесь восстановления NuGet-пакетов.
4. Нажмите **F5** (или **Ctrl+F5** для запуска без отладки).
